# 愛鯊客 Ishark 作品集網站

這是一個單頁靜態網站，GitHub Pages 的入口檔是 `index.html`。

## 維護方式

- 編輯 `index.html` 後提交到 GitHub 的 `main` 分支，即可更新網站。
- 代表作品的文案、連結與封面設定位於檔案底部的 `worksData`。
- 網頁使用 Google Fonts 的 Iansui（芫荽體）、Tailwind CDN，以及部分外部圖片網址，因此瀏覽時需要連網。
